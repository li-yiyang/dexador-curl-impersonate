#+author: 凉凉
* About
This is a trivial CFFI binding of [[https://curl-impersonate.readthedocs.io][curl-impersonate]]
([[https://github.com/lexiforest/curl-impersonate/][github@lexiforest/curl-impersonate]], making curl request
like native browser).

* Usage
** Pre-requirements
You need the [[https://curl-impersonate.readthedocs.io/en/latest/install.html][curl-impersonate]] installed first.
Or will fallback to prebuilt binary library.

** Enable curl-impersonate backend
Invoke =dexador.curl-impersonate:init= will setup the curl-impersonate
backend for dexador. After that, you can use =dex:request= normally,
the =dex:*dexador-backend*= will be set as =:curl-impersonate=.

You can call =dexador.curl-impersonate:cleanup= to unset the backend,
or just set =dex:*dexador-backend*= to something else to temperary
change the backend.

  #+name: doc:curl-easy-setopt

  #+RESULTS: doc:curl-easy-setopt
  #+begin_example
  Set the OPTION of curl HANDLE with PARAMETER.
  Return `t' for success, `nil' otherwise.

  Parameters:
  + HANDLE: foreign-pointer
  + OPTION:

    boolean switch flags
    + `:http-get' use HTTP GET method
    + `:http-post' use HTTP POST method
    + `:follow-location' if or not follow HTTP 3xx Location redirects
    + `:ssl-verify-peer' if or not verify the peer's SSL certificate
    + `:no-body' no body
    + `:verbose' if or not output verbose infomation

    boolean switch flags (0 or 2)
    + `:ssl-verify-host'
      if or not verify the server certificate's name matches host

    long
    + `:http-version' HTTP version to use, possible values:
      + `+curl-http-version-1.0+'
      + `+curl-http-version-1.1+'
      + `+curl-http-version-2.0+'
      + `+curl-http-version-3+'
    + `:post-field-size' size in bytes of the data posted
    + `:connect-timeout' seconds to wait for the connection
    + `:timeout' seconds to wait for the request to complete
    + `:max-redirs' maximum number of redirects to follow,
      -1 for unlimited

    url
    + `:url' target request URL, string or `quri:uri'
    + `:proxy' proxy URL (scheme://host:port), string or `quri:uri'

    string
    + `:key-password' passphrase for the private key given in `:ssl-key'
    + `:custom-request' custom HTTP method name to use e.g. "PATCH"
    + `:post-fields' request body to send with a POST
    + `:accept-encoding' content encodings curl should accept and
      transparently decode, "" for every encoding curl was built with.
      Note: this only enables curl's response decoding -- the
      `Accept-Encoding' request header itself keeps whatever value
      `curl-easy-impersonate' put in the `:http-header' list, so setting
      this does not change the request fingerprint

    pathname
    + `:ssl-cert' path to the client certificate file
    + `:ssl-key' path to the client private key file
    + `:ca-path' path to a directory of CA certificates for peer verification

    pointer
    + `:http-header' a foreign-pointer to curl_slist
       use `with-curl-slist' to create a curl_slist from string list
    + `:post-fields*' a foreign-pointer to raw post fields

    header-function
    + `:header-function' function as writer callback

    writer-function
    + `:writer-function' function as writer callback
  + PARAMETER: value set as curl options
  #+end_example
